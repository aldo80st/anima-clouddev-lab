# ANIMA-POL-CLOUDDEV-001 v0.1 — perfil D0 de laboratorio

Derivación minimizada de la política aprobada el 25-11-2026; no sustituye el original ni otorga autoridad adicional.

1. Cloud Preferred, Local When Required: nube elegible para trabajo portable, local para integración física/privada. Seleccionar modelo y entorno por separado. Determinismo primero y OSS-first.
2. Este laboratorio sólo admite D0 (público/sintético). D1 requiere autorización de salida; D2 requiere proveedor y repositorio expresamente autorizados; D3 no se exporta. D1–D3 fuera de este laboratorio.
3. Registrar ruta, plan, términos, imagen, límites, permisos, red, cuota, costes, repositorio y revocación. CANDIDATE → LAB_VERIFIED → ELIGIBLE; HOLD/REVOKED ante incumplimiento.
4. Admisión por orden/intent/SHA/scope/rol/autoridad/datos/coste/ownership. Aislamiento, privilegio mínimo, rama exclusiva; sin secretos, redes privadas ni acceso productivo. Autonomía interna autorizada no es autorización de efectos externos.
5. Preferir GitHub App/eventos oficiales filtrados, API oficial o CLI oficial. No scraping, extracción de tokens ni intermediación de credenciales. No disparadores amplios ni bucles.
6. Coste incremental 0 MXN; verificar cuota compartida y facturación adicional desactivada. Piloto máximo una sesión cloud, dentro del límite global vigente. No bypass de admisión.
7. Evidencia y continuidad: orden/intento, repo/SHA, session ID, recibo, UTC, hashes, tests, coste, checkpoint; UNKNOWN exige reconciliar antes de retry. Un escritor; revisor independiente. No merge/deploy.
8. Las mediciones cloud no certifican recursos locales. Comparar condiciones equivalentes. No duplicar trackers, schedulers, brokers, políticas ni persistencia por defecto.
9. Piloto CLOUDDEV-01: despacho nativo, ejecución de binario OSS real, negativos, evidencia independiente, coste cero, limpieza. Aprobación individual de ruta tras resultados.
10. Excepciones sólo por propietario con alcance/fecha/coste/datos/revocación. Moratoria de BUILD genérico intacta. Esta copia D0 no incluye inventarios, endpoints, credenciales o configuraciones internas.
